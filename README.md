# 操作系统课程实验仓库

## 仓库结构约定

- **每次实验对应一个分支**，分支名为 `labX`（如 `lab1`、`lab2`）
- 每个实验分支下固定包含两个文件夹：

```
labX/
├── code/                 # 本次实验实现后的完整代码
└── report/
    ├── report.md         # 实验报告
    ├── prompt.md         # 本次实验用到的全部 prompt 汇总
    └── images/           # 报告中引用的测试结果截图
```

`main` 分支仅保存本说明与公共配置，不放实验内容。
